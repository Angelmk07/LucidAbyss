1) Добавти текст на сцену
2) Добавти компанент Localize String Event
3) В Update String добавти ссылку на сам текст и выберите переменную text у TextMeshProUGUI
4) Зайдите в Presentation/Localization и откройте MainTable(Справа в инспекторе появится Open in Table Editor)
5) Внутри таблицы нажмите New Entry, появится новая строка
6) В столбце Key напишите название где будет использоватся текст например "Tutorial", в столбце English напишите английский текст, а в Russian русский
7) Ввернитесь к тексту на сцене и в добавленом компаненте в поле String Reference поставти только что созданные Key

Пример можно посмотреть в сцене LocalizationDemo
